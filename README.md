Recommended GitHub Pages setup

Option A: Make this your root portfolio

Create a repository named AdityaDave2008.github.io.

Upload index.html and resume.pdf to the repository root.

Open Settings → Pages.

Under Build and deployment, choose Deploy from a branch.

Select main and /(root).

Your site will publish at https://adityadave2008.github.io/.

Option B: Keep your existing project-site structure

If you want to continue using the existing aditya-portfolio repository, replace its current index.html, add resume.pdf, and GitHub Pages can continue serving the project site under /aditya-portfolio/.
